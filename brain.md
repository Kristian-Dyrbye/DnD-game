## Gotchas & Lessons
- brain.md lines are long: 100-line reads of lines 101–300 exceed the Read tool's 25k-token limit. Read lines 101+ in chunks of ~45 lines (Completed Log/Decisions are the dense part).
- Adventure labels can contain escaped quotes (`\"I'm here on the Crown's business.\" (Deception DC 13)`): grep/regex counts with `[^"]*` undercount them (95 vs the real 319). The runner appends the check label itself — never put "(Skill DC n)" in authored labels (validator error since R1). Text-level JSON patches: match `(?:[^"\\]|\\.)*` for strings. userdata/review-strip-dc.ts is the (idempotent) strip + rehash script pattern.
- CombatNarrationQueue tests: a fake narrator that waits for the abort signal must still finish normally for later jobs, or q.idle() never resolves (looked like a settle() bug, was the test).
- Full `npm test` takes ~10 s. Slow/timeouts (460 s+) mean Ollama is busy (a playtest from this or an earlier session, or aborted requests draining): check `curl -s localhost:11434/api/ps` and the playtest log mtime first. On the GPU a real playtest takes ~3 min (old CPU laptop: ~2 h; prompt eval dominated, 20–75 s first token at 2200 tokens).
- Solver/fight tests are CPU-heavy (1–4 s alone since A117) and 2–5× slower under full parallel load on the hybrid CPU → vite.config testTimeout 60 s. Timings on this PC swing ±40% run to run. Profile with `node --cpu-prof --cpu-prof-dir=<dir> --import tsx <script>` (read the `.0.001` main-thread file, not the loader thread). Solver hot path: never add structuredClone or per-call registry work in runner condition code. Running Setup.bat rewrites package-lock.json (drops `libc` fields, different npm) — restore it with `git checkout -- package-lock.json` unless deps changed.
- Encounter-starting beats keyed on flags can fire again when a later choice flips the flag: give selection beats a 'done' guard. Don't reuse one local flag across scenes. PowerShell 5 Get/Set-Content garbles UTF-8 curly quotes — edit with node/python. The solver always makes its rolls: endings that need a loss need scripted tests with an always-fail Rng.
- Fights started by onEnter or beats fire once: if they can be lost (Heroic defeat → goto elsewhere), add a rematch action or the scene soft-locks (smoke test caught this in the barrow).
- The session log is capped at 200 entries: long tests can't search early lines.
- Web saves write to IndexedDB in the background: tests must `await saves.flush()` before reopening the database. Use `new IDBFactory()` from fake-indexeddb per test for isolation. Calling `localSettingsBackend(undefined)` falls back to Node's own `globalThis.localStorage`, which prints a harmless "--localstorage-file" ExperimentalWarning.
- ui/state.ts is in the title screen's first load: never import engine/SRD modules (client/data.ts, creator, builder…) there — engine/rules/conditions.ts pulls the whole SRD via loadSrd. `npm run build:web` prints the title size; check it after touching client imports.
- Web build checks: `npm run build:web`, then `npx vite preview --mode web --port <p> --strictPort` in the background, then `node scripts/web-screens.mjs http://localhost:<p>/`. Edge's one-shot `--screenshot` (with or without virtual time) shoots before lazy chunks render and hides page errors — use the script. msedge.exe can't be run directly from Bash (needs approval) but `node` can spawn it. TaskStop on `npx vite preview` leaves the node server alive holding the port: find the PID via `node -e` + netstat and process.kill it. Client modules with import-time side effects (ui/state.ts sends new_game for `#play-*`) must load after startWebEdition (main.tsx lazy-imports App).
- Adding an NPC conversation to the demo adventure adds a `talk.<npc>.<conv>` button: tests pinning the demo square's action/suggestion lists (adventure/intent tests) and flags.test's demo flag list must be updated. A talk in progress hides exits, so tests/policies that walk a scene must `dlg.bye` first.
- New adventure JSON files must also be added to src/host/bundled.ts (the web edition can't scan folders); tests/hostInPage.test.ts fails until they are.
- fightMap only runs when a real fight starts: perform/resolveEncounter don't reveal an encounter's room (tests call fightMap). Items given with quantity > 1 may land as separate inventory entries — sum quantities.
- solveAdventure's state key ignores the clock: repeatable time-only actions (waiting) look like no-ops and get pruned — make them `once`. Legs: build the leg adventure from the raw JSON (push the stand-in beat/ending, set `start.scene`, preset flags) and validate it, or schema defaults are missing.
- Keyword intents ignore words that only name POIs present ("examine the well" won't match the well action); use other keywords.
- Beats fire in array order in one pass: a threshold beat placed before the beat that sets its input only fires next step (A068d fixes). Deadline outcomes run after beats in the same step: set what must hold after a miss inside `missed` itself.
- Git-Bash `sed -i` converts CRLF files (DESIGN.md, flags.json) to LF — re-normalize or edit with python/node. The worktree guard refuses long compound bash commands mentioning git: run git commands on their own.
- Quaternius glbs scale the armature ×100: cloned skinned meshes vanish (stale bounds → culled) unless frustumCulled=false, and Box3 must be measured after updateMatrixWorld(true) with precise=true.
- three.js GLTFLoader strips '.' from node names (KayKit `handslot.r` → `handslotr`): look bones up by the sanitized name.
- i18n: dynamic keys typecheck when built from a union (`t(\`creator.cast.${unit}\`)`); ids from data (class ids) need `as MessageKey` + a test that every id has its key. No DOM renderer is installed: UI i18n is guarded by a source scan test (creatorI18n.test.ts) — reuse its regexes for A140's game/combat screens. Client .tsx files are CRLF: multi-line node string replaces must normalize `\r\n` first (or use Edit/Write).
- i18n source scans: creatorI18n.test.ts (creator) + gameI18n.test.ts (game/combat/three/About/SaveBrowser; its `>text<` regex skips `=>` arrows and `?: Record<` generics). New UI .tsx files in those folders are scanned automatically. Multi-replacement patches: userdata/a140-patch.mjs <file> <rules.mjs> (untracked; rules = [[from, to]] exported default; keeps CRLF).
- i18n: never name a callback param `t` in a component that uses t() (TABS.map((t) => …) shadowed it). Big JSX rewrites: write the block to userdata/*.txt with Write and splice it in with a node script.
- Hub scenes with many talks (ch4 muster) can't be solved with the talks in: strip `npcs[].conversations` for that leg and test talks by script (A135).
- Conversations multiply solver states (A132: measure with a small tsx script calling solveAdventure at 20k/50k/200k nodes before deciding): after A131 the starter leg arrival→altar hit the 20k node limit and was split at "approached + key". Expect the same when adding talks to ch1–5 (A132+): split legs, don't raise limits blindly. Free-text "ask the barkeep…" now opens a conversation (refineIntent maps talk → talk.<npc>.<conv>).
- The exploratory random-walk playtest (tests/playtest.test.ts) is what catches real fight bugs (A134: split monster groups froze fights with "It is not your turn"); chapter/runner tests resolve encounters without fighting. Run the full suite after content changes to encounters.
- Big chapters can't be solved start-to-finish (solver hits node limits even at 60k): solve in legs, each with a stand-in ending that fires on the leg's milestone flag (tests/arc1Ch2.test.ts pattern).
- Deadlines check `met` before `missed`, and a scene counts as visited on arrival, so `met: {visited}` is met by a late arrival — tie `met` to a flag set by an action.
- Helper worktrees can start from an OLD base commit (A143b's was A123, not master): tell helpers to check `git log -1` and work from master's scripts; `git merge <branch>` is allowed since 2026-10-01 (cherry-pick still isn't).

- Beats gated on `world.<id>_status in_party` after a recruit fire one step later in runner tests (no roster → status written by applyParty after the step); do one more action before asserting. Chapter JSON line endings differ (ch1 CRLF, ch2 LF): patch scripts must keep the file's own EOL or the diff explodes.

- Bash heredocs / `node -e` / python heredocs die on TS template literals, backticks, `{'…` patterns ("expansion obfuscation", "unexpected EOF"): write TS files and patch scripts (userdata/*.mjs) with the Write tool and run them with node. Splitting groups breaks tests that build counts with Object.fromEntries: sum counts per id.
- Server tests that open /ws must pass a temp `savesDir` (new_game autosaves; default is <cwd>/saves).
- git core.autocrlf=true on this machine. The .bat launchers must stay CRLF; `.gitattributes` forces `*.bat` to CRLF (done). LF→CRLF warnings on `git add` are harmless.
